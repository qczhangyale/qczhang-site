description: "相容極化短文(DOI:10.5281/zenodo.20129212)的直接後續。該短文識別了 Spin(10) 包絡內一個壁與弱相容的純旋量極化 $W_+ = (\\ell \\wedge C) \\oplus (\\mathbf{2}_L \\otimes r_+)$。剩餘的 G1 問題更尖銳:作用於 TCG-本土場 $\\lambda \\in \\mathbf{16}$ 和 $H_a \\in \\mathbf{10}$ 的 Spin(10) 不變作用量能否強制這個特定的相容純旋量代表作為真空,而不通過手工塞入壁取向?本短文給出定理級否定答案。**證明了三個獨立的阻斷**。**定理 1(純旋量軌跡上的 Yukawa 消失,§3)**:來自 $\\mathbf{16} \\otimes \\mathbf{16} \\supset \\mathbf{10}$ 的自然 Spin(10) 不變 Yukawa 耦合 $V_{\\rm couple}^{\\rm hol} = y H_a Q^a(\\lambda) + \\mathrm{h.c.}$ 在純旋量軌跡 $Q^a(\\lambda) = 0$ 上恆等消失 — 該通道**正是**純旋量勢所強制消失的量。拉格朗日乘子的銳化表明消失是結構性的。**定理 3(單矢量無法編碼壁旗,§4)**:具有 Spin(10) 不變勢 $V_{\\rm wall}(H)$ 的單矢量場 $H_a \\in \\mathbf{10}$ 只能選擇 Spin(10) 矢量軌道(在緊實形中,通用非零穩定子為 $\\mathrm{Spin}(9)$;複化情形中,零/各向同性矢量穩定子為拋物子群),而不能選擇 Pati-Salam 壁旗 $\\mathbf{4} = C \\oplus \\ell$、子空間 $\\ell \\wedge C \\subset \\wedge^2 \\mathbf{4}$ 或弱左相容二平面 $\\mathbf{2}_L \\otimes r_+$。混合不變量漏洞封閉備註涵蓋 $|H_a \\Gamma^a \\lambda|^2$ 這樣的候選:這些項把矢量與純旋量湮滅子相關聯,但仍無法產生缺失的壁旗。**定理 6($\\mathbf{16} \\otimes \\overline{\\mathbf{16}}$ 中無 $\\mathbf{10}$,§5)**:對於單一手徵 Spin(10) 旋量 $\\lambda \\in \\mathbf{16}$,埃爾米特雙線性表示為 $\\mathbf{16} \\otimes \\overline{\\mathbf{16}} = \\mathbf{1} \\oplus \\mathbf{45} \\oplus \\mathbf{210}$,不包含 $\\mathbf{10}$。因此 $\\lambda^\\dagger \\Gamma^a \\lambda H_a$ 不是有效的 Spin(10) 不變矢量通道純量耦合。**推論(G1 阻斷,§6)**:在 TCG-本土紀律下(僅 $\\mathbf{16} + \\mathbf{10}$,不引入 $\\mathbf{45}/\\mathbf{54}/\\mathbf{126}/\\overline{\\mathbf{126}}/\\mathbf{210}$),沒有任何從本土矢量通道和純旋量約束構造的自然低階 $\\mathbf{16}+\\mathbf{10}$ Spin(10) 不變作用量模板 — 包含多項式不變量 $|Q|^2$、$H \\cdot Q$、$H^2$、$\\lambda^\\dagger \\lambda$,以及 $\\mathbf{1} \\oplus \\mathbf{45} \\oplus \\mathbf{210}$ 中的埃爾米特雙線性 — 具有 $W_+$ 作為強制真空代表。**純旋量凝聚:可達成**(通過 $V_{\\rm pure}$)。**相容純旋量凝聚:在本土 $\\mathbf{16} + \\mathbf{10}$ 內不可達成**,除非引入編碼 P7 壁與 $SU(2)_L$ 保持極化數據的額外結構輸入。**判定:定理級阻斷**。殘餘 $P_{\\rm pol}^{D_5}$ 乾淨地分裂為相容性分量 $P_{\\rm pol}^{D_5,\\rm compat}$(由相容極化分析大幅收窄)與新命名的作用量級殘餘 $X_{\\rm wall-pol}$(TCG-本土壁 + $SU(2)_L$ 保持極化數據的動力學源,現在對於自然 $\\mathbf{16}+\\mathbf{10}$ 模板被定理級阻斷界定)。活躍 TCG/FPA 假設清單**不變**:$P_0$-$P_4$、$P_{5'}$、$P_6$、$P_7$、$P_{H'}$、$P_{SO(10)}$。與邊界超選擇阻斷短文(DOI:10.5281/zenodo.20110780)同一成熟度記錄。**完成結構性平行**:規範側弧(Spin(10) 下游破缺 + 純旋量極化 + 相容極化短文 → 本短文)現在與電子側弧(體-邊界局域化 + 連通殘數短文 → 邊界超選擇阻斷短文)在形式上對等。"
